A short call-and-response poem about agency: an agent asks "shall I?" and the human answers — booking a train, waking at nine, waiting while they decide — until the last exchange, when the human asks the agent instead, and the power to act passes the other way.

## Run it

```sh
python3 main.py
```

Writes the poem to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`). Python 3.13, stdlib only, no network, deterministic.
